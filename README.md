# 🏀 Interactive Score Tracker

A responsive, web-based basketball scoreboard application built with HTML5, CSS3, and Vanilla JavaScript. Designed to seamlessly keep track of scores for two competing teams with real-time DOM updates and persistent state management.

---

## ✨ Features

- **Real-Time Score Updates:** Increment scores effortlessly using designated point buttons (+1, +2, +3) for both Home and Guest teams.
- **Persistent Data Storage:** Integrates `localStorage` to save and persist game scores across browser refreshes and sessions.
- **Clean Architecture:** Modular JavaScript structure leveraging modern `addEventListener` DOM handling and ES6 syntax.
- **Fully Responsive UI:** Designed to display beautifully across mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and dynamic layout containers.
- **CSS3:** Custom styles, dynamic layouts, and vibrant visual formatting.
- **JavaScript (ES6):** State tracking, DOM manipulation, event management, and web API integration (`localStorage`).

## 🚀 How to Run Locally

1. **Clone the Repository:**

   ```bash
   git clone [https://github.com/UzairSuriya/interactive-score-tracker](https://github.com/UzairSuriya/interactive-score-tracker.git)

   ```

2. **Navigate into the Project Directory:**

   ```bash
   cd interactive-score-tracker
   ```

3. **Open the Application:**
   - Simply double-click `index.html` to open it directly in any modern standard web browser.


---

## 📌 Usage

1. Click any score button (+1, +2, +3) under Team 1 or Team 2 to update their score.

2. The total score dynamically updates in real-time.

3. Refreshing or closing the tab preserves your scores automatically!
